## 📋 Publish-Schritte

### Schritt 1: Website veröffentlichen
1. Öffnen Sie das **Management UI** (rechte Seite)
2. Klicken Sie auf den **"Publish"** Button oben rechts
3. Warten Sie bis der Publish-Prozess abgeschlossen ist
4. Notieren Sie die Live-URL

### Schritt 2: Domain verbinden (optional)
1. Gehen Sie zu **Settings → Domains**
2. Option A: Ändern Sie den Auto-Domain-Prefix (xxx.manus.space)
3. Option B: Verbinden Sie Ihre eigene Domain (leipzig-photovoltaik.de)
4. DNS-Einträge bei Ihrem Domain-Provider aktualisieren

### Schritt 3: Nach dem Publish
1. Live-Website testen (alle Links, Formulare, Rechner)
2. Google Search Console: Neue URLs zur Indexierung einreichen
3. Google Business Profile aktualisieren

## 🔗 Neue URLs zur Indexierung einreichen

Nach dem Publish diese URLs bei Google Search Console einreichen:

```
https://leipzig-photovoltaik.de/gewerbe-photovoltaik-leipzig
https://leipzig-photovoltaik.de/pv-wartung-leipzig
https://leipzig-photovoltaik.de/pv-reinigung-leipzig
https://leipzig-photovoltaik.de/solarpark-betreuung
```

**So geht's:**
1. Öffnen Sie https://search.google.com/search-console
2. Wählen Sie die Property "leipzig-photovoltaik.de"
3. Klicken Sie auf "URL-Prüfung" oben
4. Geben Sie jede URL ein und klicken Sie "Indexierung beantragen"
