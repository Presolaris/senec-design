# Google Search Console Anleitung - SEO-Optimierung

**Datum:** 07.02.2026  
**Ziel:** Sitemap neu einreichen und URL-Inspektionen durchführen für optimierte Seiten

---

## 📋 Übersicht

Nach den umfangreichen SEO-Optimierungen (Schema-Markups, interne Verlinkung, Content-Updates) müssen Sie Google über die Änderungen informieren. Die Google Search Console ist das offizielle Tool dafür.

---

## 🔑 Schritt 1: Google Search Console öffnen

1. Öffnen Sie https://search.google.com/search-console
2. Melden Sie sich mit Ihrem Google-Konto an
3. Wählen Sie die Property **leipzig-photovoltaik.de** aus

---

## 📍 Schritt 2: Sitemap neu einreichen

Die Sitemap informiert Google über alle Seiten Ihrer Website.

1. Klicken Sie im linken Menü auf **"Sitemaps"**
2. Sie sehen die bestehende Sitemap: `https://leipzig-photovoltaik.de/sitemap-index.xml`
3. Klicken Sie auf die Sitemap
4. Klicken Sie auf **"Sitemap erneut senden"** oder **"Sitemap testen"**
5. Warten Sie 1-2 Minuten, bis der Status auf **"Erfolgreich"** wechselt

**Warum wichtig?** Google crawlt die Website erneut und indexiert alle Änderungen.

---

## 🔍 Schritt 3: URL-Inspektionen durchführen

Für die wichtigsten optimierten Seiten sollten Sie eine URL-Inspektion durchführen:

### Priorität HOCH (sofort prüfen):

1. **https://leipzig-photovoltaik.de/solaranlage-leipzig/**
2. **https://leipzig-photovoltaik.de/**
3. **https://leipzig-photovoltaik.de/privat/**
4. **https://leipzig-photovoltaik.de/gewerbe/**
5. **https://leipzig-photovoltaik.de/stromspeicher/**

### So führen Sie eine URL-Inspektion durch:

1. Klicken Sie oben auf das Suchfeld **"URL bei Google prüfen"**
2. Geben Sie die vollständige URL ein (z.B. `https://leipzig-photovoltaik.de/solaranlage-leipzig/`)
3. Drücken Sie **Enter**
4. Warten Sie 10-30 Sekunden, bis die Prüfung abgeschlossen ist

### Mögliche Ergebnisse:

#### ✅ "URL ist bei Google indexiert"
- **Status:** Perfekt! Die Seite ist bereits indexiert
- **Aktion:** Klicken Sie auf **"Indexierung anfordern"** um die neue Version zu indexieren
- **Wartezeit:** 24-48 Stunden bis die neue Version live ist

#### ⚠️ "URL ist nicht bei Google indexiert"
- **Status:** Die Seite wurde noch nicht gefunden
- **Aktion:** Klicken Sie auf **"Indexierung anfordern"**
- **Wartezeit:** 24-72 Stunden bis die Seite indexiert wird

#### ❌ "URL hat Fehler"
- **Status:** Es gibt technische Probleme
- **Aktion:** Prüfen Sie die Fehlermeldung und beheben Sie das Problem
- **Häufige Fehler:** robots.txt blockiert, noindex-Tag gesetzt, Server-Fehler

---

## 📊 Schritt 4: Rich Snippets prüfen

Nach der Indexierung sollten Sie prüfen, ob die Rich Snippets korrekt angezeigt werden:

1. Klicken Sie im linken Menü auf **"Verbesserungen"**
2. Wählen Sie **"Produkte"** (für Product-Schemas)
3. Wählen Sie **"FAQ"** (für FAQPage-Schemas)
4. Wählen Sie **"Lokale Unternehmen"** (für LocalBusiness-Schemas)

**Erwartetes Ergebnis:**
- **Gültige Elemente:** Anzahl der Seiten mit korrekten Schemas
- **Fehler:** 0 (wenn alles korrekt implementiert wurde)
- **Warnungen:** Sollten minimal sein

---

## 🎯 Schritt 5: Leistung überwachen

Nach 7-14 Tagen sollten Sie die Leistung überprüfen:

1. Klicken Sie im linken Menü auf **"Leistung"**
2. Wählen Sie **"Suchanfragen"**
3. Filtern Sie nach **"Solaranlage Leipzig"**
4. Prüfen Sie:
   - **Impressionen:** Wie oft wurde Ihre Seite in den Suchergebnissen angezeigt?
   - **Klicks:** Wie oft wurde auf Ihre Seite geklickt?
   - **CTR (Klickrate):** Verhältnis Klicks/Impressionen (Ziel: >5%)
   - **Position:** Durchschnittliche Position in den Suchergebnissen (Ziel: Top 3)
